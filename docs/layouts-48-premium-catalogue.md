## Customer and business contract

A Layout is a ready-to-personalize complete website with editable content and reorderable supported sections. Layout Studio uses click-on-section visual editing with a compact properties panel. Guided Mode is the default; Advanced Mode exposes registered composition options; Design Lock prevents accidental loss of design integrity while permitting valid customization.

Standard creation, built-in Layouts, editing, preview and publication on supported LUCIA addresses are free. Optional custom-domain access is ₦5,000 one-time through LUCIA Store; Paystack is the approved payment provider. Domain registration and registrar renewals are separate. None of this document authorizes checkout implementation.

S3 variables are not required for built-in designs. Use licensed optimized repository assets and existing durable website records. Follow the separately documented future S3 storage contract for genuine customer-uploaded media. Never present ephemeral uploads as persistent.

## Mandatory design excellence standard

The 48 designs must not be recolored copies. Every design must have meaningful variations in information architecture, hero geometry, visual hierarchy, navigation, grids, section ordering, mobile composition and imagery. Elegance is earned through typography, authentic content, intentional spacing and refined responsive structure—not generic gradients and excessive motion.

Each Layout must provide complete, relevant sections/pages, a working navigation, meaningful contact/enquiry mechanism, coherent footer, and realistic clearly marked demo content. Never invent testimonials, verified credentials, bookings, checkout, inventories or measured outcomes. Commerce layouts are showcase/enquiry websites unless the required backend actually exists.

The section system must register validated section types, variants and stable instance IDs. Define versioned Layout identifiers, page arrangements, tokens (type, color, spacing, rhythm), licensed assets, responsive behavior, capabilities and safe content bindings. Preview, editor and published site render the same validated structure. Creating a Layout project must persist a real project; updates must not overwrite customer edits.

Guided Mode constrains typography, spacing and layout relationships to high-quality combinations. Advanced Mode permits only implemented structural controls, no arbitrary script/HTML execution. Design Lock must have truthful state and recoverability. Content and imagery replacement should not collapse the professional design.

Every Layout undergoes phone (390px), tablet (768–1180px portrait/landscape), and desktop (1280–1440px) review, including keyboard, touch, visible focus, contrast targeting WCAG 2.2 AA, reduced motion, 200% text scaling, accessible headings and no horizontal overflow. Use appropriately licensed, optimized and responsive assets; avoid watermarked imagery or heavy continuous animation.

## Release and acceptance gates

No Layout counts as completed until evidence shows: distinct structure compared side-by-side with peers; complete useful pages; correct navigation and accessible interactions; accurate preview; real project selection; successful content edit, save, refresh, preview and publish; authenticated tenant authorization; consistent published rendering; failure recovery preserving known-good live content; responsive screenshots; media usage rights and acceptable performance.

Use an optional eight-part 0–5 design review across originality, visual polish, completeness, responsiveness, usability, accessibility, customization resilience and performance. Recommend 32/40 overall with no part below 3/5, IN ADDITION to all functional pass/fail gates. Reject near-duplicates regardless of score.

Release in quality-gated batches: 8 flagship designs (one per category), 16 polished designs (two per category), 32 expanded designs, then 48 complete designs (six per category). No weak layouts released merely to hit a numerical milestone.
